# Обучение модели

В этом каталоге лежит код, которым обучена модель `fraud_detector/models/my_catboost.cbm`.
Модель обучена на соревновательном датасете `teta-ml-1-2025`, а не взята готовой.

## Файлы

| Файл | Назначение |
|---|---|
| `train.py` | Скрипт обучения (оформлен ячейками `# %%`) |
| `submission.csv` | Сабмит для Kaggle, получен этим же скриптом |

## Запуск

Датасет нужно положить в `teta-ml-1-2025/` (скачивается с Kaggle, в репозитории его нет).

```bash
python training/train.py
```

Скрипт можно также открыть в VS Code или PyCharm и выполнять по ячейкам — они размечены
комментариями `# %%`.

## Что делает скрипт

1. Читает `train.csv` (786 431 строка, доля фрода 0.5727%).
2. Делит данные на обучающую и отложенную выборки со стратификацией
   (фродов мало, без стратификации разбиение было бы неравномерным).
3. Строит **out-of-fold** кодирование категориальных признаков средним значением
   целевой переменной: таблицы считаются по обучающей части и применяются к отложенной.
   Без этого модель увидела бы целевую переменную через кодирование, и оценка качества
   была бы завышенной.
4. Обучает CatBoost с early stopping по отложенной выборке.
5. Переобучает модель на всех данных и сохраняет:
   - `fraud_detector/models/my_catboost.cbm` — модель;
   - `fraud_detector/models/encoders.json` — таблицы кодирования и статистики;
   - `training/submission.csv` — ответ для Kaggle.

## Признаки

25 признаков, состав совпадает с тем, что ожидает сервис при инференсе:

- календарные: `hour`, `year`, `month`, `day_of_month`, `day_of_week`;
- категориальные (по 50 самых частых значений, остальные в `cat_50+`):
  `gender_cat`, `merch_cat`, `cat_id_cat`, `one_city_cat`, `us_state_cat`, `jobs_cat`;
- среднее целевой переменной по каждой категории и по каждому календарному признаку;
- `amount_log`, `population_city_log`, `distance_log`
  (расстояние между клиентом и мерчантом по формуле большого круга).

## Качество модели

Сравнение с моделью, которая лежала в репозитории изначально. Обе оценены на одной и
той же отложенной выборке, стратифицированной по целевой переменной:

| Модель | Деревьев | ROC-AUC | PR-AUC |
|---|---|---|---|
| Исходная из репозитория | 48 | 0.97937 | 0.64048 |
| **Обученная в этом каталоге** | **614** | **0.99923** | **0.96620** |

PR-AUC — основная метрика для этой задачи: фродов всего 0.57%, поэтому ROC-AUC
выглядит высоким даже у слабой модели.

## Сабмит

Метрика соревнования принимает **бинарные метки**, а не вероятности, поэтому оценки
переводятся в 0/1 по порогу. Порог выбран по отложенной выборке как максимум F1:

| Порог | F1 |
|---|---|
| 0.2 | 0.8584 |
| **0.3** | **0.8612** |
| 0.5 | 0.8421 |
| 0.98 | 0.5309 |

Порог задаётся константой `SUBMISSION_THRESHOLD` в `train.py`.
Итоговый файл содержит 262 144 строки, из них 1436 положительных (0.548%),
что близко к доле фрода в обучающих данных.
